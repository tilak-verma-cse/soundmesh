Configure Google Account Login

To enable Sign in with Google and personal YouTube playlists, create OAuth credentials in Google Cloud Console and add them to .env:

Authorized Redirect URI:
http://localhost:8765/api/auth/google/callback 
GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-client-secret

Restart the server after saving .env. You can use Guest mode right now without configuring Google OAuth.
